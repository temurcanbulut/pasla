# Pasla brand

The mark shows what Pasla does: a file passing between a computer and a phone, inside the loop of two arcs that stand for a direct, two-way transfer.

## Files

All logo files live in [`assets/brand`](../assets/brand) and are generated by [`generate.py`](../assets/brand/generate.py) (needs `fontTools` and the Inter font). Edit the script, not the SVGs.

| File | Use |
|---|---|
| `logo.svg` / `logo-dark.svg` | Mark, name and tagline, for light and dark backgrounds |
| `logo-plain.svg` / `logo-plain-dark.svg` | Mark and name only |
| `mark.svg` / `mark-dark.svg` | The mark alone, 48 px and up |
| `mark-white.svg`, `mark-mono.svg` | One-colour versions (white on brand colour; `currentColor`) |
| `icon.svg`, `icon-1024.png` | App icon: white mark on the blue tile |
| `icon-small.svg` | Simplified app icon for 32 px and below (favicon, small Windows icons): only the arcs and the file, because the devices blur together at that size |

The Windows `.ico` combines both: 16, 24 and 32 px frames come from `icon-small.svg`, 48 px and up from `icon.svg`.

## Colours

| Name | Hex | Used for |
|---|---|---|
| Navy | `#0F2A56` | Device frames in the mark, the name, headings |
| Blue | `#0D6EFB` | Primary colour, screens in the mark, app tile |
| Cyan | `#22D3EE` | The file, the arcs' light end, highlights |
| Grey | `#94A3B8` | Supporting text and lines |
| White | `#FFFFFF` | Backgrounds, the mark on blue |

In the interface, buttons use a slightly deeper blue (`#0B66EE`) so white text on them stays readable (contrast ≥ 4.5:1).

## Type

The name and headings use **Inter** (ExtraBold for the name, Bold for headings, Regular for text). In the app, the system font is used for speed and offline use.

## Please don't

- Redraw, stretch or recolour the mark, or put it on a busy photo.
- Use the full mark below 32 px; use `icon-small.svg` there.
- Use the navy mark on dark backgrounds; use the `-dark` files.
